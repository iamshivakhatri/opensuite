# OpenSuite roadmap

This is direction, not a delivery schedule.

## Current

- DOCX workspace, versions, direct editing, and agent-driven typed operations
- Self-host foundation and user-managed AI keys
- DOCX reliability, preservation, and agent performance

## Next

- Deeper DOCX fidelity and more supported operations
- PPTX and XLSX engine work
- Better document retrieval and agent context

## Later

- Broader Office workflows, collaboration, and integrations where they improve artifact-aware work
